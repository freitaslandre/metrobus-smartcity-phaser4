# MetroBus: Smart City

Jogo 2D top-down em HTML5 com **Phaser 4**, desenvolvido para a UC de
Sistemas Multimédia (2026/2027), ECGM, UNIPVC.

**Tema:** Cidades Inteligentes e Mobilidade Autónoma
**Autor:** André Freitas (n.º 33782)

## Objetivo
Conduzir um autocarro elétrico numa cidade inteligente, recolhendo e
deixando passageiros, respeitando o trânsito e gerindo a bateria.

## Conceitos técnicos
1. **V2I + Smart Grid:** semáforos inteligentes e gestão de bateria/carregamento.
2. **V2V + roteamento dinâmico:** tráfego autónomo conectado e recálculo de rotas.

## Como executar
Phaser corre no browser, mas precisa de um servidor local:
```bash
npx serve .
```
Abrir o endereço indicado (ex.: http://localhost:3000).

## Controlos
- Desktop: setas / WASD
- Mobile: joystick virtual
